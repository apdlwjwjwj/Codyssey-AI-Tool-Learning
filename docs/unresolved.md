# 미해결 기록 (Unresolved Issues)

프롬프트 규칙을 구체화하고 반복 수정했음에도 불구하고, 현재의 텍스트 기반 프롬프트만으로는 원하는 품질과 정확도를 달성하지 못한 한계 과업 2건을 기록한다.

---

## [미해결 1] 지문 내 개념만으로 새로운 수치 계산형 기출문제 창작하기

### 시도한 프롬프트 원문
```text
아래 운영체제 CPU 스케줄링(FCFS, SJF, Round Robin) 개념 설명 지문만 사용하고 외부 공식이나 예시는 절대 쓰지 않은 채로, 프로세스 4개의 도착 시간과 실행 시간이 꼬여 있는 평균 대기 시간 계산 기출문제를 새로 창작하고 정확한 정답과 풀이 과정을 출력해 줘.

[학습 지문]
FCFS는 준비 큐에 도착한 순서대로 CPU를 할당하는 비선점형 스케줄링이다. SJF는 실행 시간이 가장 짧은 프로세스에 먼저 CPU를 할당하는 방식이다. Round Robin은 각 프로세스에 동일한 시간 할당량(Time Quantum)을 부여하고, 시간 내에 완료되지 않으면 준비 큐의 맨 뒤로 보내는 선점형 스케줄링이다.
```

### 받은 결과 및 한계
- 에이플러스 튜터의 '외부 지식·공식 임의 추가 금지' 규칙과 '수치 계산형 문제 창작' 요구가 정면으로 충돌하여, AI가 문제 출제를 거부하고 대기 시간 계산 공식과 SJF 선점/비선점 기준을 추가 지문으로 입력하라며 되물었다.
- 계산 기준을 포함해 다시 요청하더라도, 텍스트 기반 생성만으로는 프로세스 4개의 시간 흐름별 큐 상태 변화와 문맥 교환 잔여 실행 시간을 추적하다가 산술 오류가 발생할 위험이 크다.

### 막힌 이유
단순 개념 정의만 담긴 강의 요약 지문에서는 수식이나 계산 절차가 생략된 경우가 많아, 외부 지식 차단 규칙을 유지한 상태에서는 새로운 수치 시나리오와 풀이 과정을 창작할 수 없다. 계산형 기출문제는 AI가 임의로 창작하게 두면 출제 거부나 오답 생성이 발생하므로, 실제 기출문제 원문과 정답을 사람이 입력해 해설 구조화만 맡기는 방식으로 역할을 제한해야 한다고 판단해 미해결로 남겼다.

## [미해결 2] 복수 조건(글자 수 + 개념 대조 + 단일 정답)을 동시에 만족하는 객관식 선지 생성

### 시도한 프롬프트 원문
```text
아래 데이터베이스 정규화 지문에서 '이행적 함수 종속 제거'와 '결정자가 후보키가 아닌 함수 종속 제거'의 개념을 비교하는 4지선다 객관식 1문제를 출제하되, 4개의 보기 문장 모두 반드시 띄어쓰기를 제외한 글자 수가 25자 이상 30자 이하가 되도록 정확히 맞춰서 출력해 줘.

[학습 지문]
제1정규형(1NF)은 모든 속성의 도메인이 원자값만으로 구성되어야 한다. 제2정규형(2NF)은 부분적 함수 종속을 제거하여 완전 함수 종속을 만족해야 한다. 제3정규형(3NF)은 이행적 함수 종속을 제거해야 한다. 보이스-코드 정규형(BCNF)은 모든 결정자가 후보키가 되도록 함수 종속을 제거해야 한다.
```

### 받은 결과 및 한계
- 첫 번째 초안에서 옳은 진술을 ①번과 ②번 두 개나 만들어 복수정답 오류가 발생하자, 출력 중간에 스스로 보기를 수정하는 사고 과정과 미완성 초안까지 그대로 노출했다.
- 출력 하단에 AI가 직접 적은 글자 수 검증 결과에서는 `(26자), (28자), (27자), (28자)`라고 표기했으나, 실제 띄어쓰기 제외 글자 수를 세어보면 각각 `26자, 27자, 27자, 26자`로 AI가 스스로 센 글자 수 카운트마저 틀렸다. 또한 글자 수를 맞추려다 보니 `"함수종속제거한다"`, `"완전종속만족한다"`처럼 조사가 생략된 비문(어색한 문장)이 생성되었다.

### 막힌 이유
LLM은 텍스트를 음절 단위가 아닌 토큰(Subword) 단위로 처리하기 때문에 정확한 글자 수 카운팅 능력이 떨어지며, 글자 수 제약·단일 정답 조건·개념 대조를 동시에 만족시키려 할 때 출력 내부에서 시행착오 텍스트가 그대로 노출되는 한계가 있다. 실제 시험 대비 문제 생성에서는 엄격한 글자 수 통제가 불필요하므로, 프롬프트로 해결하려 하기보다 후처리 검증이나 사람이 다듬는 영역으로 분리해야 한다고 판단해 미해결로 남겼다.

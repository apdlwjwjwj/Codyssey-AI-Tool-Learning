# LLM 모델 비교와 선정 보고서

## 1. 과업 정의
- **과업**: 방대한 전공 강의 필기나 자격증 요약본(텍스트)을 입력받아, 지문 내 사실만을 기반으로 핵심 개념을 구조화해 요약하고 실전 대비 예상 문제와 해설을 생성하는 일
- **타겟 사용자**: 짧은 기간 안에 방대한 이론을 빠르게 암기하고 실전 감각을 점검해야 하는 대학생 및 자격증 수험생
- **입력 데이터 형태**: 강의 노트, 자격증 핵심 요약 텍스트
- **출력 규격**: `[핵심 개념 요약]`(정확히 3줄), `[실전 예상 문제]`(4지선다 객관식 1문항 + 단답형 1문항), `[정답 및 오답 해설]`
